Twitch Radio - third-party notices
==================================

Twitch Radio itself is released under the Unlicense (see LICENSE in the source
repository). The software below is under its own licences.

Twitch Radio bundles or downloads the software below. Each project is under its
own licence; the summary here is for orientation, and the project's own licence
text is authoritative. Where a licence requires its text to accompany the
software, it is included in the installed app folder or at the link given.

Bundled programs
----------------

ffmpeg - GNU GPL (v3 or later)
    The "essentials" Windows build from gyan.dev, configured with --enable-gpl
    and --enable-version3. It runs as a separate program (ffmpeg.exe) that the
    bot starts to decode audio and encode Opus. Licence text: FFMPEG-LICENSE.txt
    in the bin folder next to it. Source code and details: https://ffmpeg.org/
    and https://www.gyan.dev/ffmpeg/builds/ - the exact source for a build is
    available from those sites on request. https://ffmpeg.org/legal.html
    The Linux builds bundle a static GPL v3 ffmpeg (version 7.0.2) from
    johnvansickle.com/ffmpeg, redistributed through
    https://github.com/eugeneware/ffmpeg-static (tag b6.1.1), also with
    --enable-gpl and --enable-version3; its licence is FFMPEG-LICENSE.txt next
    to it.

Deno - MIT
    JavaScript runtime that yt-dlp uses to run YouTube's player scripts.
    https://github.com/denoland/deno

Downloaded at runtime, not shipped
----------------------------------

yt-dlp JS challenge solver scripts - Unlicense
    https://github.com/yt-dlp/ejs
    These are NOT part of the installer. yt-dlp downloads the scripts that match
    its own version over HTTPS the first time it needs them and keeps them in
    the Twitch Radio data folder (%APPDATA%\TwitchRadio\data\yt-dlp-cache). They
    run inside Deno.

yt-dlp updates - Unlicense
    If you press "Update" in Settings > App, a newer yt-dlp release is downloaded
    from https://github.com/yt-dlp/yt-dlp (checksum verified) into
    %APPDATA%\TwitchRadio\yt-dlp.
